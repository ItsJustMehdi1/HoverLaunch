# Contributing to HoverLaunch

Thanks for your interest in helpink make **HoverLaunch**! You can help by reporting a bug, suggesting a feature, or submitting code, every one of those helps HoverLaunch's users have a better time in everyday HoverLaunch use.

## Ways to Contribute

* **Report a bug:** Found something broken or acting weird on Windows? Open an [Issue](https://github.com/ItsJustMehdi1/HoverLaunch/issues) and describe what happened, what you expected, and your Windows version.
* **Suggest a feature:** If you have an idea to make hover popups, folder nesting, or customization even smoother, open an issue to share it.
* **Improve documentation:** Typos, clearer setup instructions, or README tweaks are always welcome.
* **Submit code:** Want to fix a bug or build a new feature? Follow the pull request steps below.

## Submitting a Pull Request

1. **Fork the repository** and create a new branch from `main` (for example, `fix/popup-delay` or `feat/custom-theme`).
2. **Keep changes focused:** One bug fix or feature per pull request makes it much easier to review.
3. **Test on Windows:** Make sure the app builds and runs properly without breaking existing hover, popup, or file management features.
4. **Open a Pull Request:** Describe what you changed and why, and link any related issue.

## Guidelines

* Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
* Before starting work on a major change or new feature, we recomend you make an issue first so we can discuss the approach.

Thanks again for helping improve HoverLaunch!
