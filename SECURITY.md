# Security Policy for HoverLaunch

## Supported Versions

**HoverLaunch** is a Windows 10 and Windows 11 utility and is still being refined. Security fixes apply to the latest release on the repository.

* **Latest release (`1.1` and newer):** Supported
* **Older versions or pre-release builds:** Not supported (please update to the latest release)

## Reporting a Vulnerability

Please **do not** report security vulnerabilities in public GitHub issues.

If you find a security issue—such as unsafe file or script execution, path/shortcut issues, or a problem in `INSTALL.bat` or popup actions—report it privately to **@ItsJustMehdi1** via GitHub.

Include:
* A clear description of the issue and its potential impact
* Steps to reproduce it
* Your Windows version (Windows 10 or Windows 11) and HoverLaunch version

## What to Expect

* **Acknowledgment:** Reports will be reviewed as promptly as possible.
* **Fix & disclosure:** Once confirmed, a fix will be prepared and released before public details are shared broadly.

## Development Note

HoverLaunch is developed with AI assistance and is still evolving, so bugs and unexpected behavior can happen. Always review scripts and releases carefully before running them on your PC.
