# HoverLaunch

HoverLaunch makes accessing your desktop folders and files easier with convenient hover-activated popups.

[**Download for Windows**](../../releases/latest) · [**Report a bug**](../../issues)

---

## Features

- **Instant access** — Open folders by hovering over them.
- **Nested popups** — Navigate through folders without opening multiple Explorer windows.
- **Custom appearance** — Personalize the look of your popups.
- **File management** — Add, rename and manage files directly.
